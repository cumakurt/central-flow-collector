# Trafik anormallikleri

Kaynak: [TRAFFIC-ANOMALIES.md](../TRAFFIC-ANOMALIES.md)

Anomali değerlendirmesi mevcut saat ile önceki haftaların UTC saatlerini
karşılaştırır. Örnekleme bilgisi belirsizse sınıflandırma geri çekilir.
Sonuçlar operasyonel hacim sapmasıdır; saldırı veya güvenlik olayı teşhisi
değildir.
