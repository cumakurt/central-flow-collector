# Servis zaman çizelgesi

Kaynak: [SERVICE-TIMELINE.md](../SERVICE-TIMELINE.md)

Standart servisler protokol-aware port tanımlarıyla, özel servisler TCP/UDP/SCTP
veya Any taşımasıyla aranır. Port eşleşmesi kaynak veya hedef uçta simetriktir;
IP protocol filtresi TCP, UDP, ICMP, GRE, ESP, OSPF ve SCTP’yi kapsar.
