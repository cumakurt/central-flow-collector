# Türkçe dokümantasyon

Bu dizin, `docs/` altındaki güncel teknik belgelerin Türkçe sürümlerini içerir.
Kod, API yolları, yapılandırma anahtarları ve protokol adları değiştirilmeden
bırakılmıştır. İngilizce kaynak belgenin bağlantısı her dosyanın başında yer
alır. Makine tarafından tüketilen `openapi.yaml` için Türkçe açıklamalar
`API.md` içinde tutulur; şema dosyasının kendisi tek kanonik kaynaktır.

## Kapsam

Kurulum, yapılandırma, mimari, protokoller, üretici uyumluluğu, güvenlik,
performans, API, operasyon ve geçmiş sürüm raporları kapsanır. Geçmiş klasörü
bilerek tarihsel sonuçları korur; güncel davranış için kök `docs/` belgeleri
önceliklidir.
