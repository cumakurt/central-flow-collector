# 4.0.0 yükseltmesi

Kaynak: [UPGRADE_4.0.0.md](../UPGRADE_4.0.0.md)

Yükseltmeden önce yedek alın, mevcut yapılandırmayı doğrulayın, yeni binary’yi
kurun ve servis yeniden başlamadan `config validate` çalıştırın. Linux systemd,
Windows service ve portable OS kurulumları için ilgili installer belgesini
kullanın. Geri dönüşte installer snapshot veya doğrulanmış backup kullanılır.
