# Ürün gereksinimleri ana belgesi

Kaynak: [PRODUCT_REQUIREMENTS_MASTER.md](../PRODUCT_REQUIREMENTS_MASTER.md)

Bu belge ürün kapsamını, analiz ekranlarını, akış alanlarını, rollerini ve
gelecek yetenekleri tanımlar. Uygulama durumu için `ADVANCED-CAPABILITY-AUDIT`,
protokol ayrıntıları için `PROTOCOLS` ve API sözleşmesi için `openapi.yaml`
önceliklidir. Gereksinim maddeleri otomatik olarak uygulanmış özellik anlamına
gelmez.
