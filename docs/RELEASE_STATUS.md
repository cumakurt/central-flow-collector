# Release Status — v4.0.0

v4.0.0 is the focused Central Flow Collector & Flow Analytics release. A final package is considered releasable only after cache-free Go tests, vet/static syntax checks, split race coverage, decoder fuzzing, query/decoder benchmarks, Linux amd64/arm64 plus portable OS cross-builds, SBOM/checksum generation, UDP and IPFIX stream runtime smoke/load testing, package integrity and extracted-binary verification. Hardware/firmware certification remains outside synthetic release validation.

See `VALIDATION_REPORT_4.0.0.md` and `validation/` for the exact final run.
